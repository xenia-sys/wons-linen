# WONS orders

- The checkout takes guest orders for published, non-demo products on the production website. Billing defaults to the delivery destination unless the guest selects **Ship to a different address?** Both addresses are in Vietnam. Delivery is free; product prices already include taxes and fees. Orders are recorded in VND.
- **Place order** reserves available quantities and returns a WONS order number. The server rechecks availability and the reviewed unit price and records immutable line snapshots in the same transaction. Retrying with the same request reference and details returns the same receipt. Unsubmitted preview details remain in the page.
- **WONS Admin → Orders** is available only to active Owners. The badge counts unopened orders, refreshes approximately every 15 seconds while the workspace is visible, and updates when the Owner opens an order. The Owner contacts the customer to confirm and arrange payment. Confirmation records status; it sends no message. Cancellation releases reserved quantities for catalog variants that still exist. No payment is collected or refunded automatically.
- Keep demo items in preview. To start selling, publish genuine items with approved images, prices and real quantities; confirm support contacts and policy wording. Do not activate online payment until a separate payment integration passes acceptance checks.

Production only: the gateway credential is stored as a sensitive environment variable and as a digest in the private database schema. The data API cannot read the digest or expose orders to guests, customers, or Marketing Editors. The application uses existing Supabase/Vercel services without a service-role key. Test with `npm run build` and `npm run test:rls`; the latter rolls back synthetic fixtures in an isolated database.
