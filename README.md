# WONS LINEN

English-language Women and Men linen storefront scaffold for Next.js, Vercel and a dedicated Supabase project.

The homepage displays the approved interactive mockup. This is not a live store.

- Requirements: docs/BRD.md
- Setup status: docs/SETUP.md
- Agent instructions: AGENTS.md
- Design reference: public/design-preview.html
- Supplied logo: public/wons-logo.png

Run npm ci, complete docs/SETUP.md, then npm run dev. Validate with npm run typecheck and npm run build. Credentials belong only in ignored local files and provider configuration.
